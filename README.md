# Heart Disease Prediction using Machine Learning

## Overview

This project predicts the likelihood of heart disease using the **Framingham Heart Study Dataset**. The workflow includes data preprocessing, exploratory data analysis (EDA), feature preparation, model training, and performance evaluation.

## Features

* Data cleaning and preprocessing
* Missing value handling using mean imputation
* Exploratory Data Analysis (EDA)
* Classification model training
* Model comparison and evaluation

## Machine Learning Algorithms

* Decision Tree Classifier
* Random Forest Classifier
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Workflow

1. Load the Framingham dataset.
2. Perform data cleaning and preprocessing.
3. Handle missing values.
4. Split the dataset into training and testing sets.
5. Train multiple classification models.
6. Compare model performance and evaluate accuracy.

## Learning Outcomes

* Data preprocessing techniques
* Exploratory Data Analysis (EDA)
* Binary classification using machine learning
* Model training and evaluation with Scikit-learn
* Comparing multiple classification algorithms
